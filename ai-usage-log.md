# AI Usage Log — KursusKu

## 1. Tujuan Penggunaan AI
AI digunakan sebagai alat bantu untuk memahami konsep Laravel, memperbaiki kode, dan mempelajari alur kerja pengembangan website KursusKu.

## 2. Catatan Penggunaan AI

| No. | Aktivitas | Bantuan AI | Hasil |
|---|---|---|---|
| 1 | Pembuatan landing page | Membantu memahami struktur HTML dan Blade Laravel | Halaman utama KursusKu |
| 2 | Penggunaan Route dan Controller | Menjelaskan hubungan route, controller, dan view | Memahami Request Lifecycle Laravel |
| 3 | Pengaturan CSS | Membantu memeriksa dan menyesuaikan CSS | Tampilan website dan responsif mobile |
| 4 | Pendaftaran kursus | Membantu memahami form dan validasi | Halaman pendaftaran kursus |
| 5 | Git dan Git Log | Menjelaskan perintah Git dan riwayat commit | Memahami cara memeriksa riwayat proyek |

## 3. Cara Penggunaan
Saran dan contoh kode dari AI dipelajari dan diperiksa kembali sebelum digunakan dalam proyek. Pengujian dilakukan melalui browser dan terminal Laravel.

## 4. Catatan
File ini merupakan dokumentasi penggunaan AI dalam pengerjaan proyek KursusKu. Catatan diperbarui sesuai aktivitas yang benar-benar dilakukan.
