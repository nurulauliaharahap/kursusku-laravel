AI Usage Log  Praktikum 9

1. Tujuan

Menggunakan AI sebagai tutor untuk membantu pengerjaan proyek Laravel KursusKu, terutama pada bagian route, layout Blade, Bootstrap, form pendaftaran, dan jQuery Ajax untuk menampilkan ketersediaan kursus.

2. Prompt Penting

- Memeriksa apakah kode pada file "routes/web.php" sudah benar.
- Membantu menambahkan route untuk mengecek ketersediaan kursus.
- Memberikan panduan menjalankan dan menguji aplikasi Laravel.
- Membuat matriks pengujian sesuai Panduan Praktikum 9.

3. Saran AI yang Diterima

Saya menggunakan saran AI untuk memeriksa struktur route Laravel, menambahkan route availability yang menghasilkan data JSON, serta menguji endpoint melalui browser. Saya juga menggunakan panduan untuk memeriksa request Ajax melalui tab Network pada Developer Tools.

4. Saran AI yang Tidak Langsung Diterapkan

Route availability menggunakan ID angka 1, 2, dan 3, sedangkan formulir pendaftaran menggunakan kode WEB-01, PHP-01, dan LAR-01. Oleh karena itu, kode perlu disesuaikan agar pilihan kursus terhubung dengan benar ke fitur Ajax.

5. Verifikasi

Pengujian dilakukan dengan membuka halaman beranda, halaman pendaftaran, endpoint availability, dan memeriksa respons JSON. Pengujian Ajax, validasi form, Console, serta Network harus diperiksa langsung sebelum dinyatakan berhasil.

6. Kesimpulan

AI membantu memahami kode dan menemukan bagian yang perlu diperbaiki. Namun, setiap perubahan tetap harus diperiksa dan diuji secara langsung agar aplikasi berjalan sesuai tujuan Praktikum 9.
