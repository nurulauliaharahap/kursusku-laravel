# KursusKu

## Deskripsi Proyek
KursusKu adalah aplikasi web sederhana untuk menampilkan informasi kursus dan melakukan pendaftaran kursus secara online. Proyek ini dikembangkan menggunakan Laravel sebagai sarana pembelajaran pengembangan aplikasi web.

## Fitur
- Menampilkan halaman utama KursusKu.
- Menampilkan daftar kursus unggulan.
- Menyediakan formulir pendaftaran kursus.
- Memvalidasi data pendaftaran.
- Menampilkan hasil pendaftaran.
- Mendukung tampilan responsif pada perangkat mobile.

## Teknologi yang Digunakan
- PHP
- Laravel
- Blade Template
- HTML
- CSS
- Git dan GitHub

## Cara Menjalankan Proyek

1. Pastikan PHP, Composer, dan Laravel sudah tersedia.
2. Buka terminal pada folder proyek.
3. Jalankan perintah:

   ```bash
   composer install
   ```

4. Siapkan file `.env` sesuai konfigurasi proyek.
5. Jalankan aplikasi menggunakan:

   ```bash
   php artisan serve
   ```

6. Buka alamat berikut pada browser:

   `http://127.0.0.1:8000`
